# R Courseworks

University coursework involving statistical analysis, statistical modelling and data analysis using R.

**Grade: 81% (High First-Class)**

[View Full Coursework PDF](Statistical_Analysis_Coursework.pdf) (6 pages)

The coursework consists of two **separate** statistical analyses:

### 1. Statistical Modelling and Analysis of Rainfall Data

Analysis of 40 years of rainfall data using probability distributions and statistical modelling. The analysis involved fitting and assessing statistical models, selecting an appropriate model, estimating parameters and calculating a 10-year rainfall return level.

### 2. Statistical Analysis of a Study Assessing the Effectiveness of a New Antibiotic

Statistical analysis of clinical-trial data using point estimation and 95% confidence intervals. The analysis involved selecting appropriate inferential methods, accounting for potential confounding by hospital type, and drawing practical conclusions from the results.

## Skills Demonstrated

- R
- Statistical modelling
- Statistical inference
- Model fitting and assessment
- Probability distributions
- Parameter estimation
- Confidence intervals
- Data analysis
